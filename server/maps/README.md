# server/maps/

Welt-/Map-Daten fuer den lokalen Testserver.

World-Ordner (`world/`, `world_nether/`, `world_the_end/` etc.) sind gross, binaer und
maschinenspezifisch — **sie werden nicht committet** (siehe `.gitignore`).

## Phase 0

Es ist noch keine finale SkyPvP-Map integriert (das ist laut `docs/ROADMAP.md` erst
Teil von Phase 6 — Map Gameplay: Loot Chests, Hot Zones, King Zone, Booster-
Druckplatten etc.). Fuer lokale Tests in frueheren Phasen kann hier eine beliebige
Platzhalter-/Testwelt abgelegt werden.
